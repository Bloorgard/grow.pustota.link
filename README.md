# grow.pustota.link

Обрастание вокруг пользовательских стен и SVG.

## Что это

Механика роста из буквы Ю (alphabet.pustota.link) с двумя правками:

1. **Стены рисует пользователь.** В режиме «стены» кистью на холсте рисуются перегородки. Ластик убирает. Отмена (Z) возвращает последнее действие. Кнопка «очистить стены» стирает всё.

2. **SVG становится источником роста.** Кнопка «загрузить SVG» берёт SVG-файл, растеризует его в перегородки. Формы из файла — это стены, вокруг которых растёт узор.

## Режимы

- **Стены** — рисование перегородок кистью. Размер кисти, ластик, формат холста, отмена, очистка, загрузка SVG, экспорт PNG/SVG.
- **Рост** — побеги обрастают вокруг стен. Касание кладёт питание, рост идёт следом. Автоматический засев, полный набор параметров из полигона.

## Управление

- Касание/зажатие — питание, рост идёт за рукой
- Tab — панель параметров
- Пробел — пауза
- Z — отмена (в режиме «стены»)
- R — заново (в режиме «рост»)
- C — вручную (без авто-засева)

## Параметры роста (из полигона Ю)

- **скорость** — темп появления очагов и роста
- **масса** — толщина ветвей
- **ветвление** — частота ответвлений
- **очагов** — сколько побегов за касание
- **поголовье** — плотность кончиков
- **засев** — где сажать: у стен, у нароста, повсюду
- **просвет** — зазор между штрихами
- **звено** — длина шага ветки
- **извив** — насколько кончик блуждает
- **прямизна** — сила тяги вперёд
- **тяга к еде** — притяжение питания
- **жизнь** — длительность жизни кончика

## Формат холста

Квадрат (1:1), широко (4:3), высоко (3:4), лист (5:4)

## Экспорт

- **PNG** — растровый снимок холста
- **SVG** — векторные линии роста + стены

## Стены в режиме роста

В режиме «рост» стены видны полупрозрачными (toggle «перегородки»), чтобы было видно, где границы роста.

## Техническое

Статический сайт без сборки. Canvas, vanilla JS. Механика роста перенесена из `letters/yu.js` (alphabet.pustota.link), полный набор параметров — из полигона `lab/yu-lab.js`, режим «обрастание».
